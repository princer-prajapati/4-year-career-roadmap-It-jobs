# 🚀 4-Year IT Career Roadmap

### Build Skills. Build Projects. Build Your Career.

A modern and interactive career-planning platform designed to guide **B.Tech, B.E. and Computer Science students** through a structured four-year journey toward becoming industry-ready IT professionals.

The platform provides a clear roadmap of **what to learn, when to learn it, what projects to build, how to practice DSA, when to apply for internships, and how to prepare for interviews and placements.**

---

## 🎯 Why This Project?

Many students start their college journey without a clear understanding of:

* What programming language they should learn
* When they should start DSA
* When they should build projects
* Which skills are important for different IT careers
* When they should apply for internships
* How to build a strong resume
* How to prepare for technical interviews
* What they should focus on during each year of college

This platform organizes all of these areas into a structured **4-Year Career Roadmap**.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/4-year-it-career-roadmap.git
```

## 2. Navigate to the Project

```bash
cd 4-year-it-career-roadmap
```

## 3. Create a Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## 5. Apply Migrations

```bash
python manage.py migrate
```

## 6. Create Admin User

```bash
python manage.py createsuperuser
```

## 7. Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
